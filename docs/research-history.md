# 未采用路线记录

当前主线仅使用已验收的 PC 原生接收路径，保留原版 Steam Link 客户端。

- 公开 OpenVR 眼追提交：SteamVR 2.18.4 / Quest 3 上成功提交 381 次，NDC 随眼动变化，但 Steam Link 原生 XYZ、接收时间戳及编码裁剪不更新。未采用该后端，不代表所有其他官方接入方式均不可行。
- 外置 Android OpenXR 层：正式 Steam Link 2.0.24 不可调试，系统目录不可安装；原版加载器在独立进程的环境变量路径探针中发现 0 个层。探针没有应用 Context，不能推广为所有设备、未来版本均不可行。
- 型号伪装：没有证明仅声明眼追型号能提供编码器输入，不保留伪装入口。
- 客户端改包模拟：独立 Eye Client 曾成功驱动高清区，属于成功的协议对照实验；因目标要求原版客户端而未纳入主线。改包工具不随正式项目发布。
